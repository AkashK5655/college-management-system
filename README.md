# College Management System

## Project Overview
A web-based College Management System developed using Python and Django as part of my MCA academic project.

## Technologies Used
- Python
- Django
- HTML, CSS, JavaScript
- Docker
- AWS EC2
- Amazon ECR
- Jenkins

## Cloud & DevOps Implementation
- Prepared the Django application for containerization using Docker.
- Built and deployed a Docker image on AWS EC2 using Amazon ECR.
- Configured a Jenkins CI/CD pipeline to build the Docker image, push it to Amazon ECR, and automate deployment to EC2.
